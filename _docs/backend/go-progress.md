## 当前限制

- Go 运行程序仅提供 health；没有登录、看板业务、定向采集或持续监控，不能切换前端代理到它。现有 3002 / 5183 预览服务未被重启、替换或切换。
- 本批没有重采本机/远端 Agent 数据，没有保存真实正文或增加持久化，也没有注册自启任务。
- `go test -race` 在当前环境因 CGO_ENABLED=0 且缺少 gcc/clang 无法运行；普通测试成功不等于竞态检查通过，后续需在具备编译器的环境补验。
- 新增 Orval 链路的 undici 风险已通过精确 override 处理；既有 Vitest/tinypool 开发依赖仍有 3 条审计告警，尚未在本批升级，不应公开开发测试服务。
- OpenAPI 条件约束不能由 Go/TypeScript 类型单独保证，required nullable 必须显式构造 null；后续业务响应仍需契约测试。
